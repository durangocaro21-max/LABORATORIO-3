# TomoTherapy QA pipeline: detection of dosimetric errors in dose images

Computational pipeline to clean, characterize and classify dose images of helical TomoTherapy quality assurance (QA), developed for the course *Scientific Computing* (Master's in Biomedical Engineering, ITM). It integrates and reorganizes the code of the previous homeworks (Lab 1: dose maps, gamma index and gantry signal; Lab 2: image errors, features, statistics and classification) into a reproducible project.

## 1. Project overview

The goal of the thesis is to replace radiochromic film with the ArcCHECK diode array for the patient-specific QA of helical TomoTherapy. When the measured dose does not agree with the planned dose it is important to know **why**. This project simulates three error mechanisms and builds a pipeline to detect them:

| Class | What it simulates |
|---|---|
| `normal` | small random variations only |
| `noise_error` | increased detector noise |
| `shift_error` | positioning shift of the phantom (a fraction of a pixel) |
| `output_error` | wrong output (the whole dose is scaled by 1.5-4 %) |

The pipeline has three logical modules (`src/`):

1. **`preprocessing`**: synthetic data generation, cleaning with Pandas and preparation of the signals.
2. **`analysis`**: feature extraction, statistics, feature selection, classification and the numerical algorithms (gamma index, derivative/integral, complexity).
3. **`visualization`**: all the figures.

## 2. Theoretical background

* **Patient-specific QA in helical TomoTherapy.** In helical delivery the gantry rotates continuously while the couch moves, so the dose is delivered from many angles at once and its verification is more complex than for conventional treatments. The traditional verification with radiochromic film has limitations (single use, long preparation and analysis, variability in handling and digitization) (Yang et al., 2017). ArcCHECK is a cylindrical diode array (1386 diodes in a helical arrangement) that can measure the dose from many gantry angles in one acquisition and can be reused.
* **Gamma index.** It compares a measured and a planned dose distribution by combining a dose-difference criterion and a distance-to-agreement criterion (Low et al., 1998); the recommendations for measurement-based verification QA are given by AAPM TG-218 (Miften et al., 2018). Machine-specific tests, such as the gantry speed, are described in AAPM TG-148 (Langen et al., 2010).
* **Feature-based characterization.** The difference between the measured and the planned image is described with spatial features (intensity statistics and edges) and frequency features (2D power spectrum). The discriminative power of the features is evaluated with hypothesis tests (ANOVA / Kruskal-Wallis selected with the Shapiro-Wilk test), the Fisher Discriminant Ratio, the AUC and feature selection (ReliefF and mRMR; Peng et al., 2005).
* **Algorithms and complexity.** The algorithms are analysed with Big-O notation and measured with `timeit` and `cProfile`. The Fast Fourier Transform (Cooley & Tukey, 1965) is the divide-and-conquer version of the `O(N^2)` discrete Fourier transform and is used for the spectral features.

## 6. Methodology (summary)

1. **Data.** 120 synthetic images of 64 x 64 pixels (30 per class) exported as messy CSV files: dead and hot pixels, impossible negative values, duplicated images, files in percent and 12 spellings of the 4 labels. A synthetic gantry-angle signal (3 rotations) is also generated.
2. **Cleaning (Pandas).** Remove duplicates, unify scale and labels, wide-to-long reshaping, replace impossible values, detect hot pixels with a rolling median (the threshold is larger than the noise, so the noise is preserved), interpolate with `groupby` + `transform`, merge labels and the planned image, keep a 52 x 52 region of interest and go back to a 3D array.
3. **Features.** 8 spatial and 5 frequency features calculated from the difference image (measured − planned).
4. **Statistics.** Shapiro-Wilk → ANOVA or Kruskal-Wallis, pairwise tests with Bonferroni, Fisher Discriminant Ratio, one-vs-rest AUC, redundancy analysis.
5. **Separability and classification.** PCA, silhouette, logistic regression and k-NN with hold-out and repeated stratified cross-validation (accuracy, precision, recall, F1, ROC-AUC).
6. **Algorithms of Lab 1.** Gamma index (3 %/3 mm), numerical derivative and integral of the gantry angle, each one with loops and vectorized.
7. **Complexity.** Computing time vs input size and empirical order of growth.

## 7. Summary of the results

(Fixed random seed; the complete tables are in `results/tables/`.)

* **Cleaning.** 6 duplicated images, 2583 missing pixels, 246 impossible values and 492 hot pixels were found; 3195 pixels were corrected.
* **Statistics.** Normality was rejected for at least one class in all the features, so Kruskal-Wallis was used; 12 of 13 features differ significantly between classes (p < 0.001), the exception being `s_skew` (p = 0.95). The best features by Fisher ratio are `s_gain_dev` (3.6), `f_low` and `f_high` (about 3.3).
* **Classification (repeated 5-fold cross-validation, macro F1).** Spatial features 0.85 (logistic regression) and 0.84 (k-NN); frequency features 0.63 and 0.56; all the features 0.85 and 0.86. With all the features and logistic regression the out-of-fold accuracy is 0.85 and the macro ROC-AUC is 0.97.
* **Gamma index (3 %/3 mm).** Mean pass rate: `normal` 99.9 %, `output_error` 97.3 %, `noise_error` 95.8 %, `shift_error` 93.8 %.
* **Gantry signal.** Mean speed of 12.0 deg/s and a total rotation of 1076 degrees against the expected 1080 (error of −0.37 %).
* **Complexity.** The empirical order of growth is about 2 for the DFT with nested loops and for the gamma index with loops (in the image side), about 1 for the derivative/integral with loops, and the vectorized and FFT versions are much faster.

## 8. Discussion

No single feature separates the four classes: `s_gain_dev` identifies the output error, and the spectral and edge-based features distinguish the noise from the shift. The spatial set already reaches the maximum performance, because the spectral features are highly redundant (18 pairs of features with |r| ≥ 0.95) and cannot separate the output error from the shift by themselves (both produce smooth, low-frequency differences). The gamma pass rate detects that an image is not normal, but it does not tell the cause, which is the reason to use the features. The most difficult class is `normal` (F1 = 0.71), because the weakest errors (a very small shift, a gain error of 1.5 %) are inside the normal variability. The vectorized implementations give exactly the same results as the loops but are much faster, and the FFT is the key to compute the spectral features efficiently. Because the data are synthetic and the classes were designed by me, the results cannot be interpreted as the performance of the real system.

## 9. Conclusions

* A reproducible pipeline, organized in three modules, was built from the raw inconsistent files to the evaluation of the classifiers, and every function is documented and tested.
* The cleaning must preserve the signal of interest (the noise is not removed as outliers).
* Complementary features are needed, and the redundancy of the feature set justifies the use of feature selection.
* The weak errors are the main difficulty, so the tolerance levels will have to be defined with real measurements.
* The same pipeline is designed to be applied to the real ArcCHECK data once the thesis protocol is approved.
